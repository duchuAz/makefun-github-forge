A standalone GitHub-compatible git forge built for make.fun's **Build a GitHub-compatible git forge** bounty ($500 in USDC): git smart HTTP, the REST v3 API, GraphQL v4 and MCP from one Node 22 process and its own in-memory store.

## Run it

```sh
node main.ts
```

The process binds an ephemeral port, registers it with `$MAKEFUN_ENV_URL`, serves the forge, then exits when the env says the trial is done.
